FILIP SHOOP - AndroidIDE Setup

1. ফোনে AndroidIDE ইনস্টল করুন।
2. এই ZIP ফাইলটি Extract করুন।
3. AndroidIDE খুলে Extract করা FilipShoop folder-টি Open/Import করুন।
4. Gradle sync শেষ হতে দিন। প্রথমবার Android Gradle Plugin/Gradle/SDK download চাইতে পারে—Allow/Install দিন।
5. Build > Assemble Debug APK চালান।
6. APK সাধারণত app/build/outputs/apk/debug/app-debug.apk এ তৈরি হবে।
7. APK-তে tap করে Install করুন।

Package: com.filipshoop.app
App name: Filip Shoop

নোট: এটি WebView app। Website-এর কিছু online resource (Tailwind CDN, FontAwesome, Google Fonts, TradingView) ব্যবহারের জন্য Internet permission দেওয়া আছে।
